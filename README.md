# Thanh Duy

Fullstack developer. I mostly work with Go on the backend and React on the front. Currently building [SayReal](https://sayreal.org) — a sober driver booking app in Vietnam.

**Frontend** — React, Next.js, TypeScript, Flutter, Riverpod
